## Setup, Controls, and Troubleshooting on PC

### Installing and First Launch

Install from your storefront of choice, then launch once and immediately check the video and audio options. Legacy indie games frequently default to a fullscreen resolution your monitor no longer uses, which produces a black screen or a badly stretched image. Switching to windowed mode first, then choosing a resolution that matches your display, saves a lot of frustration.

If the game refuses to start at all, right-click the executable, open Properties, and try running it in compatibility mode for an older Windows version, along with "Run as administrator."

### Controls on Sublustrum PC

The control scheme follows the classic point-and-click model. Expect the mouse to do almost all of the work.

| Input | Typical function |
|---|---|
| Mouse movement | Look around, pan the view, aim the cursor |
| Left click | Interact, walk to a point, pick up items |
| Right click | Examine, cancel, or open the inventory |
| Scroll wheel | Cycle inventory items or zoom |
| Escape | Pause menu and options |
| Function keys | Quick save and quick load in some builds |

Exact bindings can differ between builds, so confirm them in the options menu before you start. There is no meaningful controller support to speak of; this is a mouse-and-keyboard game at heart.

### Common Problems and Fixes

If you run into trouble, most **Sublustrum PC** launch problems come down to a short list of causes.

| Symptom | Likely cause | What to try |
|---|---|---|
| Game will not launch | Missing legacy runtimes | Install the older DirectX redistributable and run as administrator |
| Black screen at startup | Fullscreen resolution mismatch | Launch in windowed mode and reset resolution |
| No sound | Wrong output device or legacy audio | Set your default device, then try compatibility mode |
| Cursor offset or too fast | Windows display scaling | Disable DPI scaling for the executable |
| Stuttering or frame drops | Overlay software, uncapped framerate | Disable overlays and cap the framerate |
| Crashes when saving | File permissions | Install outside Program Files and run as administrator |

These fixes are drawn from player experience rather than an official support document, but they cover the overwhelming majority of reports.

## Tips for Your First Playthrough

Sublustrum does not hold your hand, and that is a feature rather than a flaw. A few habits will make the **Sublustrum PC** experience far smoother.

| Tip | Why it matters |
|---|---|
| Slow down and read everything | Notes and environmental detail carry the story |
| Keep a notepad nearby | Puzzles lean on symbols and patterns you see only once |
| Pan the camera constantly | Interactables hide at the edges of the frame |
| Save often, in multiple slots | Experimentation is part of the design |
| Play with headphones in a dark room | The sound design is half the atmosphere |
| Resist the walkthrough | The "aha" moments are the reward |

If you get stuck — and most players do at least once — step away for a few minutes rather than opening a guide immediately. The puzzles are built around observation, and the answer is usually something you have already seen but not yet connected.

## FAQ

### Can I still play Sublustrum on PC today?

Yes. The game is a self-contained, lightweight Windows title, and it runs on modern hardware without demanding upgrades. Most players only need to check the store listing, install it, and adjust the resolution on first launch.

### Where is the best place to buy the Sublustrum PC version?

Start with the official Steam listing, since that is where availability and pricing are easiest to verify. Other digital stores occasionally carry it as well, but catalogs shift, so confirm the listing is live before you pay.

### What are the real system requirements?

The game is far lighter than anything released in the last decade. Any modern dual-core PC with integrated graphics and a few gigabytes of RAM will handle it comfortably. For the developer's exact published requirements, check the store page.

### Does Sublustrum support controllers on PC?

Realistically, no. It is a mouse-driven point-and-click adventure, and the interface is designed around a cursor. Keyboard shortcuts exist for menus and saves, but a gamepad adds nothing here.

### Is Sublustrum scary?

It is unsettling rather than frightening. There are no jump-scare set pieces to speak of; the tension comes from tone, sound, and the persistent feeling that you are somewhere you should not be.
